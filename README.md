# Student Marks Manager

A simple Student Marks Manager built using Python.

## Features

- Add Student
- View Students
- Find Topper
- Exit Program

## Concepts Used

- Functions
- Dictionaries
- Loops
- Conditional Statements
- User Input Handling
- Menu-Driven Programming

## Menu

1. Add Student
2. View Students
3. Find Topper
4. Exit
